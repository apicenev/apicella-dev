BookTrackr – Reading & Knowledge Hub

BookTrackr is a personal web application that turns reading into a structured learning process. Instead of only tracking which books I’ve finished, it captures what I’ve learned and how I apply it, building a searchable knowledge library that grows with every book.

Books are found via the Open Library API and move through a reading pipeline (wishlist → to read → reading → finished). Notes can be marked as key insights, tagged and linked across books, while action items turn ideas into concrete next steps. One-tap progress logging feeds a stats page with yearly goals, streaks and reading pace. It’s built with React, TypeScript and Firebase, secured by Firestore rules, covered by Vitest tests and deployed on Vercel.
